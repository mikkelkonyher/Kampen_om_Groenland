# Kampen om Grønland

Satirisk 2D endless runner lavet i Unity 6 (6000.0.60f1).

Trump kører i en slæde trukket af JD Vance over indlandsisen. Undgå sæler,
klimaforskere og Mette Frederiksen, og saml bitcoins, MAGA-caps, Jeff Bezos og
Nobels fredspris. Opbakning er dit liv — rammer den 0, bliver du ikke genvalgt.

## Styring

- **W / S** — skift spor
- **Enter** — vælg i menuen

## Kør projektet

Åbn mappen i Unity Hub med Unity 6000.0.60f1 og start scenen `Assets/Scenes/MainMenu.unity`.
